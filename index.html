设置

图标 URL 前缀。留空（推荐）时自动匹配当前部署环境：本地双击、nginx 内网、外网域名都会自动生成对应链接；填写后强制使用「前缀 + icons/文件名」。

站点名称

自定义网页标题与左上角站点名称（服务模式对所有访问者生效）。

语言

选择页面显示语言，保存后自动刷新。

显示

图标卡片名称是否显示文件后缀名。

账号安全

修改管理员用户名或密码（服务模式对所有访问者生效）。

登录防护

服务模式专用：连续登录失败达到次数后，按设定时长锁定该账户；填 0 表示不限制。

网站图标

填写图标 URL，或选择本地图片自动转为地址；保存后左上角站点图标与浏览器标签页图标（favicon）同时更新。

分类管理

添加的分类立即可用；删除分类时，该分类下的图标会移到「其他」。基础分类删除后如需恢复，重新添加同名分类即可。

备份与恢复

备份：把全部图标与数据打包成「项目名_时间戳.zip」下载到本地。重新部署后点「恢复」导入该压缩包即可还原所有数据（服务模式还原 icons/ 与 data/ 目录，静态模式还原浏览器数据）。

上传的图标（0 个）

上传的图标保存在当前浏览器本地。发布到 nginx / 外网前，请先「下载图片」放进项目 icons/ 目录，再把下方记录粘贴进 data.js，即可长期生效。
